Descripción General

¿Qué problema resuelve?

El equipo de QA y liberaciones genera diariamente correos técnicos, reportes RDL, mensajes de Telegram y documentos de validación UAT. Antes de esta plataforma, todo se redactaba manualmente, provocando errores de formato, inconsistencias y pérdida de tiempo.

Release Notifier QA automatiza la generación de todos estos artefactos desde una interfaz unificada.

Módulo: Correo de Liberación

Propósito: Generar correos HTML formateados para notificar al equipo sobre una nueva liberación de software.

Campos del formulario

SecciónCampoTipo
VersionesVersión a publicarSegmentado (AA.SS.PP)
VersionesVersión rollbackSegmentado
PublicaciónFechaDate picker
PublicaciónURL de releaseURL
ArtefactosMódulos, Citrix, DLL, WinterX, ScriptsCheckboxes
BranchesMódulos, WinterXTexto
ComplementosSPs, Proyectos, NotasTextarea

Exportaciones

PDF • Markdown • HTML • Portapapeles (para Outlook)

Módulo: Mensaje Telegram

Propósito: Generar mensajes texto para el grupo de Telegram del equipo de infraestructura.

Importa datos desde el correo de liberación. Incluye: acción, scripts, versiones, cambios, branches y rollback.

Módulo: Reportes RDL

Propósito: Documentar reportes, stored procedures y proyectos distribuidos con cada liberación.

Cada ítem RDL contiene: nombre, carpeta, URLs (Megang/NTRS02), paths, SP asociado y proyecto.

Módulo: RFC Técnico

Propósito: Documentar formalmente la validación técnica de un RFC con persistencia en base de datos.

Secciones

  1. Información general
  2. Contexto del cambio
  3. Objetivos
  4. Componentes técnicos
  5. Reglas de negocio (dinámicas)
  6. Casos de prueba (dinámicos)
  7. Bugs relacionados (dinámicos)
  8. Conclusiones
  9. Notas finales

Módulo: VoBo UAT

Propósito: Generar correos de solicitud de validación UAT con formato corporativo e imágenes de evidencia.

Soporta bloques dinámicos (texto + imagen) para documentar pasos de validación.

Preguntas frecuentes

¿Dónde se guardan los datos de RFC Técnico?

En H2 embebido en ./data/rfcdb.mv.db. Persisten entre reinicios.

¿Se pierden los borradores al cerrar el navegador?

No. Se almacenan en localStorage y se restauran automáticamente.

¿Cómo exporto a Outlook?

Click "Copiar" → Outlook → Nuevo correo → Ctrl+V.

¿Funciona sin internet?

Sí, excepto la fuente Inter (Google Fonts). Toda la lógica es local.
