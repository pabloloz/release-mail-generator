CONTEXTO

El problema que existía

⏱️
Proceso 100% manual
Redactar cada correo desde cero consumía 15-30 min por documento
⚠️
Errores frecuentes
Rutas incorrectas, versiones equivocadas, formato inconsistente
🔄
Duplicación de trabajo
Misma información capturada múltiples veces en distintos formatos
📂
Sin trazabilidad
No había historial de qué se envió, cuándo ni con qué contenido
VISIÓN

Objetivos del proyecto

⚡
Automatizar
Generación de correos y documentos con un clic
🎯
Centralizar
Toda la información en una sola plataforma
🛡️
Reducir errores
Validaciones y autocompletado inteligente
📐
Estandarizar
Formatos corporativos consistentes siempre
🚀
Productividad
Reducir tiempos de 30 min a menos de 5
📊
Trazabilidad
Historial completo de documentos generados
TÉCNICO

Arquitectura del sistema

Backend
Spring Boot 4
Java 17 · REST
Frontend
Thymeleaf + JS
Bootstrap 5 · SPA
Base de datos
H2 Database
Embebida · JPA
Exportación
OpenPDF
PDF · Markdown · HTML

Usuario → Navegador → Spring MVC → Servicios → H2 DB
↳ PDF Engine · Email Generator · Markdown Builder
